# OASIS SURVIVOR

![Title Scene](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Title.png)

**OASIS SURVIVOR**는 Unity 3D로 제작된 **뱀서라이크 + 소울라이크** 장르의 PC 게임입니다. 일반 스테이지에서는 3인칭 뱀서라이크 형식의 전투를, 보스 스테이지에서는 1인칭 소울라이크 형식의 전투를 경험할 수 있습니다.

---

## 주요 기능 (Key Features)

- **하이브리드 장르**: 뱀서라이크의 **랜덤 스킬 조합** + 소울라이크의 **정밀한 전투 시스템** 결합
- **듀얼 스테이지 시스템**:
  - **일반 스테이지**: 3인칭 시점의 뱀서라이크 형식 진행
  - **보스 스테이지**: 1인칭 시점의 소울라이크 형식 진행
- **진행 시스템**:
  - 레벨업 시 **랜덤 스킬 선택** (`공격력 강화`, `방어력 증가`, `특수 능력` 등)
  - 홈 화면에서 재화를 사용한 **영구 스탯 강화**

## 게임플레이 (Gameplay)

### 일반 스테이지 (3인칭 뱀서라이크)
![Normal Stage](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Normal.png)
- **탐색**: 광활한 맵에서 자원 수집 및 적 생성 구역 탐험
  
![Skill Selection](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Skills.png)
- **스킬 선택**: 레벨업 시 3개의 랜덤 스킬 중 선택 (최대 6개 조합 가능)



### 보스 스테이지 (1인칭 소울라이크)
![Boss Stage](https://github.com/dreamer603/Narsha-project/blob/main/OasisSurvivor_Boss.png)
- **전략적 전투**: 보스의 패턴 분석 및 타이밍에 맞춘 회피/공격
- **스태미너 관리**: 공격/방어 시 스태미너 소모 시스템
